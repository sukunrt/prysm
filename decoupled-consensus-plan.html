Decoupled Consensus: The Final Plan

The real gadget, one cutover at the fork, no parallel FFG run.

Goal

Build the real finality gadget: Fresh Simplex, with the height filter and the timeouts. Use real vote content on the real beacon state. Measure the time to finality, the timeout rounds under loss, and the stalls under partition. The traffic measurement comes free.

The cutover

There is no parallel run. Before the Heze fork, FFG runs alone. At the fork, the attestation duty stops, and two new duties start. After the fork, the FFG code path serves the pre-fork slots only.

The two vote streams

The available attestation is the head vote. It is built. It waits for the block, or for 25% of the slot. It is 201 bytes on one global topic.

The finality vote goes out at the slot start. Its fields freeze at the round start. It copies the attestation path: the types, the subnet and aggregate topics, the duties, and the block-body list. The seen-cache key changes from epoch to round. The slot-start collision with the block is a primary measurement.

The head rule

The Goldfish gate is the head input. Score the children with the votes from the previous slot. Then apply the majority gate. The gate must be live at the fork. If it is not, all head weights are zero.

Build order

Networking first, then the middle. This is a code order, not a runtime order. Finality is not measurable before step (e). Unit tests carry the correctness load. Do not build view-merge or the TSQ duty.

  1. Add the round math: compute_round_at_slot and its inverse. A sub-round is one slot. A round is 8 slots. The duty and the seen-cache need this first.
  2. Add the finality vote message with dummy content, on the cloned attestation path: the types, the subnet and aggregate topics, and the block-body list. The seen-cache key is the round, not the epoch.
  3. Build the send path: the duty at slot start, fields frozen at round start, one vote per validator per round. Dummy values until (e).
  4. Build the receive path: gossip validators with real verdicts. Check structure, timing, and signature. Semantic checks come with (e).
  5. Build the middle: the new store fields beside the FFG fields, the clockless state machine driven from handleBlockAttestations with the branch order unit-tested, and the four interface swaps: the anchor cascade, the height filter, the lexicographic updates, and the prune from store.F. Do not compare the gadget with FFG: it gets no votes after the fork.

Rules

Quorums count validators. targets and timeouts are sparse maps. After the fork, only the gadget prunes. Until step (e) is in, nothing prunes and memory grows: keep the runs short. If the gadget stalls, pruning stops. Watch for it.

Open

Pad the registry with exited validators to get the mainnet state size.

Authority
